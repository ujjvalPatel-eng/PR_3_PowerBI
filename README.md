# Sales Analysis Dashboard -- PR_3

## Project Overview

This project is an interactive **Sales Analysis Dashboard** built in
Microsoft Power BI. It presents sales-related insights across multiple
report pages, helping users explore overall performance, geographic
patterns, and payment and review information.

## Dashboard Pages

### 1. Sales Overview

Provides a high-level view of sales performance and key summary metrics.

### 2. Geographic Analysis

Helps explore sales performance across geographic locations and compare
regional patterns.

### 3. Payments and Reviews

Presents insights related to payment methods and customer review
information.

## Tools and Technologies

-   **Microsoft Power BI Desktop** -- report development and interactive
    visualizations
-   **Power Query** -- data import and transformation, where applicable
-   **DAX** -- measures and calculations, where applicable

## How to Use

1.  Download or clone this project folder.
2.  Open `PR_3.pbix` using Microsoft Power BI Desktop.
3.  If Power BI prompts you for data-source access or credentials,
    follow the prompts and update the source path if required.
4.  Use the report page tabs to navigate between **Sales Overview**,
    **Geographic Analysis**, and **Payments and Reviews**.
5.  Use slicers, filters, and visual interactions (if available) to
    explore the data.

## Notes

-   The `.pbix` file contains the Power BI report and its model/report
    configuration.
-   If the original data source is stored separately, make sure it is
    available and correctly connected before refreshing the report.
-   Dashboard figures depend on the underlying dataset and any filters
    applied.
